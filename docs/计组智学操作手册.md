## 1. 产品概述

计组智学是为《计算机组成原理》课程量身打造的AI教育智能体，采用"教-学-评-辅"闭环设计理念，深度融合教学日历、课程标准、实验指导书和超星题库四大数据源，提供六大功能模块，助力学生高效学习、教师精准教学。

**核心特色：**
- 🤖 7×24小时AI智能答疑
- 🕸️ 可视化知识图谱
- 📈 个性化学习路径推荐
- 💻 实验代码智能调试
- 📝 动态抽题自测系统
- 📊 教师端学情分析

## 3. 部署安装

### 3.1 本地开发运行

```bash
# 1. 克隆项目
git clone https://github.com/luochan1028/jizu-zhixue.git
cd jizu-zhixue

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev

# 4. 浏览器访问
# 访问 http://localhost:5173/
```

### 3.2 生产环境构建

```bash
# 1. 构建生产版本
npm run build

# 2. 构建产物位于 dist/ 目录
```

### 3.3 Nginx部署

```nginx
server {
    listen 80;
    server_name your-domain.com;

    root /var/www/jizu-zhixue/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # 静态资源缓存
    location /assets/ {
        expires 7d;
        add_header Cache-Control "public, immutable";
    }
}
```

## 4. 功能模块操作指南

### 4.1 智能问答模块

#### 功能说明
智能问答模块支持自然语言交互，学生可以就课程内容自由提问，AI提供精准、已审核的回答。

#### 操作步骤
1. **进入模块**：点击左侧导航栏"智能问答"，进入问答界面
2. **查看热门问题**：页面顶部展示5个热门问题，点击即可快速提问
3. **输入问题**：在底部输入框中输入问题，点击发送按钮或按Enter键提交
4. **查看回答**：
   - AI逐字呈现回答，支持Markdown格式（标题、加粗、列表、表格）
   - 回答底部显示"教学团队已审核"标识
5. **关联资源查看**：
   - 教学日历：查看对应周次学习内容
   - 微课资源：观看关联的视频/文档/练习
   - 知识点标签：点击跳转到知识图谱
6. **隐私提示**：所有学习数据本地化存储，不用于模型训练

#### 截图参考
- 热门问题区域：页面上方，带知识点标签（基础/难点/重点/常考）
- 对话区域：左侧AI回答，右侧用户提问
- 底部：输入框+发送按钮+隐私提示

### 4.2 知识图谱模块

#### 功能说明
以可视化图谱形式展示课程核心概念及其关联关系，支持交互式探索。

#### 操作步骤
1. **进入模块**：点击左侧导航栏"知识图谱"
2. **画布操作**：
   - 拖拽平移：鼠标按住空白处拖动
   - 滚轮缩放：鼠标滚轮放大/缩小
   - 工具栏：点击右上角 🔍+ / 🔍- / ↺ 按钮缩放或重置
3. **节点交互**：
   - 点击任意节点，关联节点和连线高亮，不相关节点变暗
   - 连线上显示关系文字（如"包含"、"控制"等）
4. **详情面板**：
   - 显示选中节点名称、分类标签、详细描述
   - 跨模块跳转：点击"💬 在问答中提问"或"📝 做相关练习"
   - 关联知识点：点击列表切换查看
5. **学习路径建议**：底部展示5步学习路径（数据表示→运算方法→存储系统→CPU设计→IO系统）
6. **图例说明**：左下角展示各分类颜色对应的知识点类别

#### 节点分类
| 颜色 | 分类 |
|------|------|
| 紫色 | CPU核心 |
| 青色 | 运算/存储部件 |
| 绿色 | 存储系统 |
| 黄色 | 指令系统 |
| 粉色 | IO/总线系统 |

### 4.3 学习路径模块

#### 功能说明
"教-学-评-辅"闭环的核心模块，提供个性化学习建议与进度追踪。

#### 操作步骤
1. **进入模块**：点击左侧导航栏"学习路径"
2. **查看统计数据**：顶部7张统计卡片
   - 总学习时长、总体进度、已答题数
   - 正确率、活跃天数、累计问答、实验调试
3. **掌握度雷达图**：六维能力可视化展示
4. **章节进度**：
   - 各章节学习进度条
   - 掌握度百分比
   - 薄弱知识点红色标签标注
5. **本周学习计划**：
   - 课前预习任务（可勾选）
   - 课后巩固任务（可勾选）
   - 与教学日历自动联动
6. **待完成任务**：
   - 按类型分类：预习/练习/实验/复习
   - 显示截止日期
7. **个性化推荐**：
   - 薄弱点专项突破
   - 拓展阅读材料
   - 实验预习建议
8. **学习报告**：
   - 点击"生成学习报告"按钮
   - 查看学习概况、优势知识点、薄弱知识点、实验表现
   - 每项含评分和改进建议

### 4.4 实验辅助模块

#### 功能说明
为汇编语言实验提供代码级智能调试支持，帮助学生快速定位和修复代码错误。

#### 操作步骤
1. **进入模块**：点击左侧导航栏"实验辅助"
2. **选择实验项目**：左侧列表点击切换不同实验（实验2数码转换、实验3分支循环、实验4子程序设计等）
3. **编写/上传代码**：
   - 在中间编辑器直接编写代码（支持8086汇编语法高亮）
   - 点击"📎 上传代码"按钮，上传.asm文件
   - 工具栏：🔄 重置 / 📋 复制
4. **智能调试**：
   - 点击"⚡ 智能调试"按钮
   - 右侧显示调试结果：
     - 🔴 错误列表：红色标记，含行号和修复建议
     - 🟡 警告列表：黄色标记
5. **查看修复建议**：
   - 点击"查看修复建议代码"
   - 弹出代码对比弹窗：左侧原始代码，右侧修复代码
   - 红色=删除行，绿色=新增行
6. **优化建议与评分**：
   - 代码优化建议
   - 代码质量评分（进度条展示）
7. **实验小贴士**：左侧底部提示汇编编程注意事项

### 4.5 自测系统模块

#### 功能说明
支持按知识点和难度动态抽题，即时反馈成绩与薄弱点分析。

#### 操作步骤
1. **进入模块**：点击左侧导航栏"自测系统"
2. **抽题配置**：
   - 选择知识点：点击知识点网格按钮（支持多选）
     - 包含：Cache映射、IEEE 754、DMA方式、指令系统、布尔代数等12个知识点
   - 选择难度：简单 / 中等 / 困难
   - 选择题量：5题 / 10题 / 15题 / 20题
   - 查看题库匹配信息
   - 点击"开始答题"
3. **答题界面**：
   - 左侧面板：
     - 答题进度环形图
     - 题目导航网格（点击跳转）
     - 收藏题目列表
     - 知识点分布
   - 中间答题区：
     - 题号 + 难度标签 + 知识点标签
     - 题目内容
     - A/B/C/D选项（点击选择）
     - 🔖 收藏按钮
     - ⏱ 计时器
   - 答案解析（提交后显示）
4. **提交与成绩**：
   - 答完后提交
   - 显示奖杯、正确题数、正确率、用时
   - 薄弱知识点识别
   - 按钮：重新抽题 / 查看解析

### 4.6 教师端学情分析

#### 功能说明
为教师提供班级学情数据可视化分析，支持教学决策优化。

#### 操作步骤
1. **进入模块**：点击左侧导航栏"学情分析"（教师端分区）
2. **班级统计**：
   - 各班级卡片：班级名称、学校图标
   - 活跃用户进度条
   - 平均分
   - 完成率
3. **高频问题TOP10**：
   - 序号排名（前3名粉色高亮）
   - 问题内容
   - 分类标签
   - 趋势箭头：↑上升 / ↓下降 / →平稳
   - 提问次数
   - 频次进度条
4. **知识点掌握度**：
   - 渐变色柱状图
   - 各模块掌握度百分比
5. **教学调整建议**：
   - 3列卡片布局
   - 基于高频问题趋势自动生成
   - 例如："Cache映射相关提问上升22%，建议增加课堂练习时间"
6. **数据用途**：
   - 定位教学难点
   - 调整教学节奏
   - 优化教学设计

## 6. 常见问题

### Q1：AI回答不准确怎么办？
A：所有AI回答均经过教学团队审核，标注"教学团队已审核"标识。如发现问题可联系教师反馈。

### Q2：学习数据会被上传吗？
A：不会。所有学习数据均本地化存储，不用于模型训练，保护学生隐私。

### Q3：支持哪些浏览器？
A：推荐使用Chrome或Edge浏览器，版本90以上。Firefox和Safari也可使用，但部分语音功能可能受限。

### Q4：如何反馈bug或建议？
A：可通过课程教师反馈，或发送邮件至项目邮箱。

### Q5：演示视频没有声音怎么办？
A：请检查浏览器是否允许自动播放语音，或点击右下角音量按钮取消静音。

### Q6：云主机上的程序挂了怎么办？
A：已配置systemd自动拉起服务，程序异常退出后会自动重启。详见第3.4节。
